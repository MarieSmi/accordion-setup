Интерактивный прототип окна конструктора Saby: показывает, как настраивается левый аккордеон
(навигация по приложению) — добавление страниц, подменю и их редактирование.
Нужен для презентации, поэтому публикуется по ссылке.

Создан как копия прототипа настройки интерфейса (https://github.com/MarieSmi/interface-prototype) — история до разделения общая.

## Договорённости

- Стек: обычные HTML + CSS + JavaScript, без сборки.
- Контентная область свёрстана: Главная (две вкладки), скелетон страницы раздела, информеры и ЦУ.
  Скриншотами остались отдельные картинки внутри виджетов (графики, превью «Магазина», аватары).
- В шапке конструктора работают «Меню», «Логотип», «Тема», «Фон», позиционирование контента, отмена / повтор и меню «Язык» (только ховеры);
  остальные кнопки (вид экрана, «⋯», ↺, масштаб, ✓, ✕) — только наведение.
  Что делает каждый клик, решается отдельно.
- Всё, что меняется в прототипе, живёт до перезагрузки страницы.
- Окно конструктора — фиксированная сцена 1600×900, вписывается в окно браузера с сохранением пропорций.

## Поведение аккордеона

- Клик по пункту аккордеона открывает его **подменю**, страница при этом не меняется.
- Клик по пункту **внутри подменю** переходит на страницу.
- Клик по **строке шапки** аккордеона («saby», пустое место) — переход на «Главную». «+» и птичка — отдельные зоны.
- Птичка (логотип) — кнопка: своя подсветка при наведении, клик открывает окно «Логотип» (то же, что кнопка «Логотип» в шапке конструктора).
  Исключение — узкий аккордеон (любой вид, в том числе панель): птичка там не кнопка, без своей подсветки, клик по ней ведёт на «Главную», как по всей шапке.
- Бургер сворачивает раскрытый аккордеон в узкий и разворачивает обратно — как пункты «Широкая» и узкие виды в окне «Меню».
  При наведении — круг со стрелками «свернуть» / «развернуть» (Figma `xMQ3ZEN4AUINgwjVoxR8hS`, `16189-61353`). У панели бургера нет.
- Наведение на пункт подсвечивает его, через задержку появляются команды ✎ и ⋮.
  В «Общем демо» в меню ⋮ «Переместить → Вверх / Вниз» меняют пункт местами с соседом (закреплённый внизу остаётся последним, отменяется в шапке);
  у второй строки — пункт подменю в своей колонке. «В другой раздел» — только ховер.
- Раздел текущей страницы отмечен синей полоской слева.
- Если открыт пункт подменю, в раскрытом аккордеоне под разделом появляется вторая строка с названием пункта;
  раздел и пункт выделены одним блоком, полоска — у пункта. Клик по второй строке открывает подменю раздела.
- Подменю есть у всех разделов. Заголовок подменю ведёт на страницу раздела (у «Задач» он называется «Задачи на мне»).
  Исключение — «Учет» и «Маркетинг»: у них заголовок только подпись (не кликается, без ховера, в редакторе его нет).
  Ховер заголовка подсвечивает только название, без иконки. У многоколоночного подменю заголовок по ширине первой колонки,
  колонки — по самому длинному пункту (не уже 188px). ✎ — у всех подменю во всех видах аккордеона; ✕ — только у подменю, открытого по клику (при наведении подменю закрывается само, у панели ✕ тоже нет): по нему будет открываться редактор подменю.
- Иконка в заголовке подменю встаёт ровно на иконку пункта. Исключение: подменю, которое не помещается до низа окна,
  поднимается вверх, и иконка сдвигается (так решили, бывает у нижних разделов, когда под разделом показан выбранный пункт).
- Подменю закрывается по ✕ (если открыто по клику), клику вне его или Esc.
- Открытие подменю (по клику или по наведению) и вид аккордеона настраиваются в окне «Меню» (см. ниже).
  По умолчанию: раскрытый аккордеон, открытие по клику (`DEFAULTS` в `app.js`).
- В режиме «по наведению» подменю закрывается, когда курсор уходит с аккордеона и подменю.

## Окно «Меню»

- Открывается по кнопке «Меню» поверх неё (левый край по кнопке, верх по верху шапки, как в макете). Закрывается ✓ и ✕. Клик мимо окна его не закрывает.
- Окно перетаскивается за шапку в пределах окна конструктора; при следующем открытии снова встаёт на кнопку.
- Изменения применяются к аккордеону сразу, кнопки «Сохранить» нет. ✓ и ✕ просто закрывают окно.
- ↺ возвращает исходные настройки. Пока настройки исходные, кнопка серая.
- «Состояние панели» — ссылка, открывает список из четырёх видов (превью-плиток нет):
  - **Широкая** — раскрытый аккордеон; «Открывать подменю» — по наведению или по клику;
  - **Узкая с названиями** — иконки с короткими подписями, подменю открывается как настроено;
  - **Узкая без названий** — только иконки, подменю только по наведению («По клику» недоступно);
  - **Раскрывается по ховеру** — узкая панель, при наведении раскрывается поверх контента на 200px,
    подменю только по наведению, без заголовка и ✕.
- Подменю по наведению (в раскрытом и узком аккордеоне) и подменю узкого аккордеона открывается справа от аккордеона,
  вровень с пунктом, с жирным заголовком раздела. Поверх пункта, с иконкой раздела — только по клику в раскрытом аккордеоне.

## Окно «Логотип»

- Открывается по кнопке «Логотип» поверх неё, перетаскивается, закрывается ✓ и ✕ — как «Меню».
  Из шапки аккордеона (клик по птичке) окно встаёт углом на угол шапки аккордеона, кнопка «Логотип» в шапке конструктора при этом не подсвечена.
  Повторный клик по птичке закрывает окно.
  Открыто всегда только одно окно настроек: открытие «Логотипа» закрывает «Меню» и наоборот.
- Превью шапки аккордеона: птичка и «saby». Наведение на птичку показывает скрепку поверх неё,
  клик открывает меню «Иконка».
- Меню «Иконка» открывается так, что скрепка в его заголовке встаёт на место птички.
- Ссылки при наведении темнеют (#153f6f) и подчёркиваются.
  Любой пункт («С компьютера», «Из коллекции») подставляет случайную иконку из своего набора
  (`assets/img/logos/`) — сразу в шапку аккордеона и в превью.
- ↺ возвращает птичку. Пока логотип стандартный, кнопка серая.
- «Действия по плюсу» — только список: наведение на строку подсвечивает её и показывает команды ⚙, 🗑, ⋮.
- Пока не делаем: ссылки «Выберите» (коллекция) и «сделайте текстовый логотип», кнопки «+» и «папка»
  в «Действиях по плюсу», команды строк, корзину у логотипа.

## Редактор подменю

- Открывается по ✎ у пункта аккордеона (команда по наведению) и по плавающей ✎ у подменю. Подменю закрывается,
  на его месте встаёт окно редактора: иконка в шапке окна — ровно на иконке пункта (во всех видах аккордеона).
  Не помещается до низа окна — поднимается, как подменю.
- Пока окно открыто, конструктор недоступен (без затемнения), клик мимо окна его не закрывает. Окно перетаскивается за шапку.
- Шапка: иконка раздела, название раздела, «+», отмена, повтор, ↺, ✓, ✕.
  Клик по названию — правка на месте (каретка — где кликнули, под текстом линия; Figma `butxp53vLxrXFluHM61BfU` `17493-35508`): Enter или клик мимо применяют, Esc отменяет. Новое название после ✓ — в аккордеоне; заголовок подменю — отдельная сущность, название раздела его не меняет.
- Клик по иконке открывает панель выбора иконки (Figma `44fX18O5Huk4hmoaANMNIC` `10506-57779`, без выбора цвета):
  недавние, «Люди», «Статусы пользователя», «Финансы»; вкладки справа прокручивают к группе (у остальных вкладок групп в макете нет),
  поиск пока не ищет. Выбранная иконка попадает в черновик (с отменой) и после ✓ — в аккордеон и подменю.
  Панель встаёт поверх иконки (левый верхний угол в углу иконки), прокрутка без полосы. Закрывается ✕, Esc или кликом мимо.
- Все пункты подменю — виджеты, первый — заголовок подменю (кроме «Учета» и «Маркетинга», где заголовок — подпись). Колонки сохраняются; в редакторе они одинаковой ширины — по самой широкой.
- Наведение на список (колонку, на всю высоту окна) — рамка и плюсы по сторонам; на виджет — рамка виджета, список при этом тоже подсвечен. Клик выделяет виджет
  (рамка, плюсы сверху и снизу, список — пунктиром); снимается по Esc или клику мимо. Плюсы пока ничего не добавляют.
- Там, где есть окно настроек пункта (реестр двухколоночный): ховер только у виджета, колонки пунктиром не выделяются, между колонками — линия.
  Плюсы сверху и снизу — у выделенного виджета и по ховеру на любом; плюс открывает меню «+», страница встаёт в список над / под ним и выделяется.
  Виджет добавляется на своём уровне — на уровне того, у чьего плюса его добавили: у вложенного — тоже вложенный (в ту же группу), у пункта 1-го уровня — 1-й уровень.
  Нижний плюс пункта с вложенными (и заголовка подменю с вложенными) ставит новый под всей группой, чтобы тот не забрал чужие вложенные; клик по пустой колонке — тоже меню «+», страница встаёт в неё.
- Над выделенным виджетом — тулбар: заменить, ⚙ (только там, где есть окно настроек пункта), удалить, ⋯. У пустой колонки — заменить (меню «+», выбранная страница встаёт в колонку и выделяется), удалить и ⋯; в ⋯ — «Заменить» и «Удалить».
  ⋯ — меню «Заменить», «Настроить» (как ⚙), «Переместить» → «Вверх» / «Вниз» (виджет меняется местами с соседом, уровень не меняется; у заголовка подменю нет) и «Удалить».
  Повторный клик по выделенному виджету (и двойной клик по тексту) — переименование на месте: появляется каретка, тулбар не меняется.
- Виджеты перетаскиваются: зажать и тянуть (сдвиг от 4px) — виджет остаётся на месте бледным (40%), за курсором (правее и ниже) едет его копия без обводки (75%), остальные стоят на месте;
  место вставки — линия между виджетами (@info_border-color 60%, 4px, скругление, 8px от краёв виджета; где виджет и так стоит — линии нет); колонка пунктиром не выделяется. В пустую колонку (реестр) виджет бросают в саму ячейку: она обводится пунктиром, линии нет. Цвета info — токены ui-kit. Можно в другую колонку,
  под заголовок подменю. Отпускание — один шаг отмены, виджет остаётся выделен. Заголовок подменю не перетаскивается; вторая колонка без виджетов пропадает.
  Вложение — «бросить виджет в виджет»: курсор над серединой пункта 1-го уровня или заголовка подменю — тот обводится пунктиром 1px снаружи (6 / 3, @info_border-color 60%), линии нет;
  отпускание кладёт виджет в него вложенным (2-й уровень) первым среди его вложенных (так «От меня», «На контроле»… вложены в «Задачи на мне»).
  Вложенность — только два уровня: во вложенный пункт (2-й уровень) вложить нельзя — над ним пунктира нет, только линия вставки (например, «Новости» не кладутся в «Доверенности»,
  оба остаются вложенными в «Аналитику»). Пункт, вложенный в другой, сам становится 2-м уровнем вместе со всеми своими вложенными. В закреплённый внизу пункт вложить тоже нельзя.
  У пункта с вложенными (и у заголовка подменю, если в него вложены пункты) справа от названия — стрелка из cbuc-icons: ⌄ — вложенные видны, › — свёрнуты.
  Клик по стрелке сворачивает / разворачивает вложенные (без выделения виджета; выделенный вложенный при сворачивании — выделение на родителя). Это вид редактора, а не правка:
  в отмену не идёт, на подменю не влияет. Пункт перетаскивается со вложенными: у копии за курсором стрелка свёрнута (›), после отпускания группа свёрнута или раскрыта, как была до перетаскивания; бросить виджет в свёрнутый — тот раскрывается.
  Пункт 1-го уровня перетаскивается вместе со своими вложенными. Вставка линией перед вложенным пунктом — тоже вложенный, в остальных местах — 1-й уровень.
  Линия, после которой виджет встанет вложенным, короче — с отступом слева, как текст вложенных.
  Сразу после последнего вложенного пункта группы уровень выбирается курсором по горизонтали: правее 40px от левого края виджетов — в конец группы
  (2-й уровень, линия с отступом, как текст вложенных), левее — на 1-й уровень (линия во всю ширину). Так вложенный достаётся наружу, в том числе последний — на своём же месте.
  «Заменить» (значок «Обновить», cbuc-icons EBD1) открывает меню «+» (без «Добавить виджет» и «Добавить колонку»): выбранная страница встаёт на место виджета, уровень и закрепление сохраняются, виджет остаётся выделен; отменяется одним шагом.
- Меню «+» (Figma `9eLwMJLQCwT0xHKviN2j1P` `16090-257796`): строка поиска встаёт вровень с «+», левый край — по «+».
  Поиск фильтрует страницы. Раскрываются группы «Моей компании» (О компании, Новости, Структура, Сотрудники, База знаний)
  и «Отчетность» (Отчетность, Письма, Требования) — клик по странице
  добавляет её виджетом в конец первой колонки. Остальные группы без содержимого, «Добавить виджет» — только наведение. Строки «Добавить колонку» нет.
- Новая колонка (там, где есть окно настроек пункта: «Общее демо», «Подменю → Редактор») — плюсами по краям карточки и перетаскиванием. Пока колонка одна и ничего не выделено,
  наведение на карточку обводит её рамкой (@info_border-color 60%; карточка при этом не выделяется) и показывает по центру её левого и правого края белые точки — те же плюсы, что у виджетов.
  Подсветка одна: при наведении на виджет рамка и плюсы с карточки снимаются (подсвечен только виджет), к плюсам — через поле карточки вокруг виджетов.
  Плюс слева / справа открывает меню «+»: выбранная страница встаёт первой в новой колонке с этой стороны и выделяется. Колонок — не больше двух; удаление последнего виджета второй колонки убирает и её.
  Перетаскивание виджета за левый / правый край карточки — та же рамка и вертикальная линия у края (как линия вставки, 4px); отпускание ставит виджет (со вложенными) в новую колонку.
  Сценарий «Добавление колонок» — на одном экране два редактора подменю «Документы» из 5 пунктов (✓ аккордеон не меняет): слева «Как в общем демо» — как описано выше, справа «Линия у края». Живой редактор один: на месте второго варианта — его копия, курсор на ней меняет их местами, правки каждого варианта сохраняются. В «Линии у края» карточка рамкой не обводится (ни при наведении, ни при перетаскивании): у левого и правого края — зона по высоте колонки,
  при курсоре в ней — тонкая бледная линия (1px, @info_border-color 60%, как рамка ховера виджета) на месте линии вставки и по её центру белая точка, как у плюсов виджетов; плюсом она становится при наведении на неё.
  Заголовок подменю всегда над первой колонкой: при новой колонке слева он со своими вложенными переезжает в неё, новый пункт встаёт под ними.
  Поэтому слева колонку можно добавить, только если в старой останутся пункты (у подменю из одного заголовка — только справа).
- Delete удаляет выделенный виджет. Отмена / повтор — по каждому изменению; ↺ возвращает исходное подменю из макета.
- ✓ применяет изменения к аккордеону и подменю; ✕ при изменениях спрашивает «Сохранить изменения?» — стандартное окно подтверждения по центру (Да / Нет / Отмена, Esc = «Отмена»).
- Изменения живут до перезагрузки страницы.
- Пока не делаем: содержимое остальных групп меню «+», «Переместить → В другой раздел».

## Шапка конструктора: позиционирование контента

- Три кнопки: «Слева», «По центру», «Растянуть» (по умолчанию).
- «Растянуть» — контент на всю рабочую область 1538px. «По центру» / «Слева» — блок 1238px (аккордеон + середина + информеры + ЦУ)
  по центру области или у её левого края, по бокам — фон страницы.
- Переход плавный (300 мс): меняется ширина середины, аккордеон и ЦУ идут за её краями. Открытое подменю закрывается.

## Шапка конструктора: меню «Язык»

- Клик по «Язык RU» открывает меню языков (Figma `16065-176561`): RU, EN, KK, FR, UZ, AR, HE и «•••».
- Строка выбранного языка (RU) — на высоте кнопки, ✕ меню — поверх ✕ шапки. Закрывают ✕, клик мимо и Esc.
- Пока только ховеры: выбор языка и «•••» ничего не делают.

## Шапка конструктора: отмена и повтор

- «Отменить» / «Повторить» откатывают и возвращают изменения на странице: открытие подменю (по клику / по наведению),
  логотип, позиционирование, «Информеры», тему, свои цвета и фон, состав и названия вкладок, разделы (после ✓ редактора подменю).
- В историю не пишутся переключения: вид панели аккордеона (бургер, «Состояние панели»), активная вкладка, выделение,
  открытие окон и подменю, переходы по разделам.
- Шаг — одно действие (клик, отпускание ползунка); ввод в поле — один шаг после паузы. Новое изменение отбрасывает шаги «вперёд».
- Нечего отменять / повторять — кнопка серая. Смена сценария во вспомогательной панели начинает историю заново.
- Открытое окно «Вкладки» при отмене закрывается; окна цвета и фона остаются открытыми и показывают восстановленные значения.

## Главная и виджет «Вкладки»

- Контент свёрстан: середина — Главная или скелетон страницы раздела (один на все разделы), справа информеры и ЦУ — одинаковые на всех страницах.
  В колонке информеров «4 квадратика» неактивные (#ccc, Figma `nuC4KFMiS36uDWDUp9wKGl` `17890-9860`), «СС» — прозрачность 40%.
- На Главной виджет «Вкладки» (Figma `xMQ3ZEN4AUINgwjVoxR8hS` `18731-100134`): «Главный» (дашборд) и «Для менеджеров» (`18771-29704`).
  Новые и дублированные вкладки показывают пустую ячейку конструктора (Колонки / Виджет / Строки).
- Наведение — рамка 60%; клик по вкладке переключает содержимое и выделяет виджет (рамка и тулбар «+ ⚙ ⋯» над ним), клик мимо снимает выделение.
- Второй клик по активной вкладке — переименование на месте (Enter или клик мимо — применить, Esc — отменить). Вкладки перетаскиваются мышью.
- «+» — меню «Вкладка»: работает только «С чистого листа», остальные пункты статичны. «⋯» — «Добавить» и «Настроить» (меню по ширине текста). ⚙ — окно «Вкладки».
- 🗑 (после ⚙) — удаляет все пользовательские вкладки (кроме «Главного»), виджет пропадает. Если есть только одна новая нетронутая
  вкладка («Страница N» без переименования) — сразу; иначе — окно «Вы собираетесь удалить все пользовательские вкладки. Продолжить?»
  («Да» — удалить, «Отмена» или Esc — оставить).
- Окно «Вкладки» встаёт справа от виджета (8px), перетаскивается. Экраны:
  - список — строки перетаскиваются, команды ⚙ (открыть вкладку), дублировать, удалить (у первой вкладки удаления нет);
  - вкладка — поле названия; новая вкладка появляется, как только в поле есть текст. «‹» или Enter — назад к списку.
- Изменения сразу видны на дашборде. ↺ возвращает всё как было при открытии окна, ✓ закрывает,
  ✕ при изменениях спрашивает «Сохранить изменения?» («Нет» — вернуть как было).
- Уход с Главной закрывает окно и меню (изменения остаются) и снимает выделение.
- Сценарий «Из тулбара → +вкладка» (вторая вилка: «Плюс в тулбаре» и «+вкладка», как у «Из шапки дашборда»): та же ссылка «+вкладка» в колонке информеров под «4 квадратиками», повёрнута
  (читается снизу вверх, «+» внизу). Открывает меню «+», «+» меню — ровно поверх «+» ссылки; после добавления вкладки ссылка пропадает.
  «4 квадратика» на это время скрыты, ссылка стоит на их месте.
- Сценарий «Из шапки дашборда → По чипсе»: вместо ссылки «+вкладка» в шапке — чипса «вкладки» (Figma `nuC4KFMiS36uDWDUp9wKGl 18813-5910`,
  style contrast: белая, 24px, на ховере рамка #d0d0d0). Клик открывает меню «+» поверх чипсы: «+» меню по её середине, над началом слова, «С чистого листа» добавляет виджет вкладок, чипса пропадает. Точки-подсказки у неё нет.
  «По чипсе с фильтрами» — та же чипса, справа от неё фильтры, как в «С фильтрами».
- Подсказки в сценариях добавления вкладки: бирюзовая точка 6×6 (Figma `18348-17461`) у плюса в колонке информеров
  и у ссылки «+вкладка» в шапке дашборда (справа вверху). Пропадает после добавления вкладки и пока открыто меню «+».
  Сценарии «Из шапки конструктора» и «Из магазина» убраны.
- Виджета «Вкладки» в «Магазине» нет: вкладки добавляются только по «+» в тулбаре. На скелетоне страницы раздела (страница не виджетируется) этого «+» нет.

## Тема оформления

- Кнопка «Тема» в шапке открывает панель «Тема оформления» (Figma `xMQ3ZEN4AUINgwjVoxR8hS` `16090-237338`) справа на всю высоту.
  Тема применяется сразу по клику на плашку, ✓ и ✕ просто закрывают панель.
- 10 системных тем (плашки без подписей; `THEMES` в `app.js`): `blue`, `pink`, `dark` (по умолчанию), `gray-blue`, `night`,
  `gray-pink`, `gray-red`, `dark-full` (тёмная на всю страницу), `graphite`, `mint`.
  Тема красит фон за контентом, аккордеон, подменю и акценты («Акцентный 2», синий, — маркер выбранного пункта; «Акцентный», рыжий, — активная вкладка и красные заголовки).
  Светлые темы: аккордеон прозрачный, наведение и выбранный пункт — оттенок акцента, а не серый. `dark-full` красит и карточки, текст, скелетон, ЦУ.
- Наведение на большое превью показывает «Настроить» — открывает расширенные настройки (список цветов темы, только ховеры), «‹» — назад.
- Рядом с «Тема» — три кружка: цвет аккордеона (нет цвета — перечёркнутый круг, полупрозрачный — шахматка), «Акцентный» (рыжий), «Акцентный 2» (синий).
  Клик по кружку — окно выбора цвета над этим кружком (левый край на 23px левее него): палитра, HEX и прозрачность. Цвет применяется сразу; выбор цвета из палитры ещё и закрывает окно, ввод HEX и прозрачности — нет; ✓ и ✕ закрывают, ↺ возвращает как было при открытии окна.
- Свой цвет делает тему пользовательской: в панели появляется группа «Пользовательские» с одной плиткой над «Системными»,
  дальше она обновляется при каждой перенастройке. Выбор системной темы её не удаляет.
- Под свой цвет аккордеона подбираются текст и оттенки: светлый — тёмный текст и серые оттенки, тёмный — светлый текст, прозрачный — как светлые темы.

## Окно «Фон»

- Кнопка «Фон» (подпись и кружок) в шапке; окно по Figma `16385-63244` встаёт поверх кнопки: левый край — по её левому краю, верх — по верху шапки. Esc и ✓ / ✕ закрывают.

  Поля сохраняются по ✓ в черновик и по «Сохранить» в аккордеон: «Широкой» — название пункта (то же, что в шапке окна), «Узкой» — название в узком аккордеоне;
  «Узкой» и «Выбранный пункт», пока их не меняли, повторяют название.
  Двойной клик по названию пункта — переименование на месте, тулбар остаётся (кнопка тулбара сначала применяет название). Закрепления снизу в редакторе нет.
  Панель выбора иконки встаёт кружком цвета на иконку пункта.
  Перетаскивание пунктов — как в редакторе подменю: нажатие выделяет пункт; сдвиг от 4px — пункт остаётся на месте бледным (40%), за курсором (правее и ниже) едет его копия без обводки (75%),
  остальные стоят на месте; место вставки — линия между пунктами (@info_border-color 60%, 4px, 8px от краёв пункта; где пункт и так стоит — линии нет).
  Отпускание — один шаг отмены, пункт остаётся выделен. Закреплённый внизу не перетаскивается, под него другие не встают.
  Вложение — «бросить пункт в пункт», как в подменю: курсор над серединой другого пункта — тот обводится пунктиром (6 / 3, @info_border-color 60%), линии нет.
  Отпускание переносит пункт в подменю того пункта первым пунктом (под заголовком подменю и его вложенными); из аккордеона он уходит.
  Его подменю переезжает вместе с ним — вложенными под ним (2-й уровень): заголовок подменю — первым вложенным, если подпись отличается от названия раздела
  («Задачи на мне» остаётся, «Контакты» — нет); колонки — подряд; вложенность глубже становится 2-м уровнем (больше двух уровней не бывает); закрепление снимается.
  Например, «Контакты» в «Задачи»: «Задачи на мне» (с «От меня» … «Разобрать»), «Контакты» с вложенными «Группы» … «Заявки», дальше «Доски» и остальные.
  Выделен — пункт, в который вложили; отменяется одним шагом, в аккордеон — по «Сохранить». В закреплённый внизу вложить нельзя.

## Общее для окон

- Переход с дашборда на другую страницу приложения (аккордеон, подменю, шапка аккордеона), когда в конструкторе есть несохранённые правки
  (история отмены не на исходном шаге), — окно «Сохранить изменения текущей страницы?» в оформлении «Сохранить изменения?»:
  «Да» — правки остаются, «Нет» — откатываются, в обоих случаях переход и история заново; «Отмена» или Esc — остаться.
  Со страницы с заглушкой окна нет: правки остаются, история начинается заново.
  Пока для демонстрации окно показывается при любом уходе с дашборда, и без правок (`NAV_CONFIRM_ALWAYS` в `app.js`; `false` — только при правках).

- На сцене открыто одно окно: «Меню», «Логотип», панель тем, выбор цвета, «Фон», «Вкладки», окна правой панели, редактор подменю и меню «Язык» — открытие любого закрывает остальные.
- Меню со списком (выпадающие списки, «Язык»): ховер пункта — фон #f3f4f8, у невыбранного пункта на месте маркера пустой кружок
  (Figma `nuC4KFMiS36uDWDUp9wKGl` `18013-12953`).
- Тултип: только «На главную» на строке шапки аккордеона (и на птичке в узком аккордеоне), через 500 мс под курсором.

## Открытые вопросы

- В «Документах» в макете дважды «База знаний» — перенесено как есть.
- Цвета наведения, которых нет в макете (пункты подменю, правая панель, «+» в аккордеоне, ✓/✕),
  подобраны вручную — нужны точные значения.
- Для всех страниц из подменю сейчас показывается один скелетон из макета «Контакты».
- Меню «Язык»: положение подобрано по скриншоту (строка RU — на высоте кнопки, ✕ меню — поверх ✕ шапки), узла с размещением нет.
- Выбор языка должен попадать в историю отмены, но пока он ничего не меняет — записывать нечего.
- Положение точек-подсказок у плюса и ссылок «+вкладка» подобрано по скриншотам.
- В редакторе подменю подобраны вручную: ховер «+», ховер иконки в шапке, ховер и выделение текущей иконки в панели выбора.

## Отступления от макета

- В подменю нет счётчиков, стрелок «›» и «+» (у «Заметок») — решили не делать.
- Счётчики у пунктов подменю пока скрыты — в подменю аккордеона и в редакторе подменю (стили, `styles.css`); в сводной «Виды подменю и пунктов» видны.
- В заголовке подменю профиля — фото и «Сдобников С.В.», как в аккордеоне (на скриншоте — инициалы «КК» и другое имя).
- Текст на тёмном фоне (аккордеон, подменю, превью логотипа) тоньше — начертание 350, иначе он выглядит жирнее, чем в макете.
- В иконке календаря — сегодняшнее число.
- Надпись «saby» (шапка аккордеона и превью в окне «Логотип») — SVG из контуров Maison Neue Extended Book: шрифтом браузер рисует её мягче, чем Figma. Файл шрифта в проекте не нужен.
- Положение подменю узкого аккордеона и панели (справа, вровень с пунктом) выбрано сами — сценариев в макете нет.
